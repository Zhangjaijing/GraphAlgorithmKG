## 🧮 算法概览

### 核心算法组件

#### 1. Schema检测算法
- **TF-IDF特征提取**: 文档关键词密度分析
- **本体匹配算法**: 实体类型关键词匹配
- **置信度融合**: 多维度评分加权计算
- **LLM辅助决策**: 置信度相近时的语义判断

#### 2. 动态Schema发现
- **问题驱动生成**: 基于用户查询的LLM Schema生成
- **数据驱动发现**: 频繁模式挖掘和概念聚类
- **增量演化**: 概念漂移检测和增量更新
- **交互式优化**: 主动学习和用户反馈

#### 3. 实体推断算法
- **6层分层推断**: 缓存→Schema→模式→关键词→上下文→Unknown
- **渐进式策略**: 从快速到精确的推断层次
- **置信度评估**: 每层推断的可信度计算

#### 4. 三元组抽取算法
- **规则优先策略**: 结构化模式优先匹配
- **质量评估**: 规则抽取结果的质量评分
- **LLM兜底**: 规则不足时的智能补充
- **混合融合**: 多种抽取结果的去重合并

## 🔬 算法特点

### 创新点
1. **多Schema智能选择**: 解决单一本体局限性
2. **动态Schema生成**: 从静态到自适应的升级
3. **分层认知推断**: 平衡准确性与效率
4. **符号神经混合**: 结合规则和LLM优势

### 技术优势
- **高准确率**: 多层验证确保抽取质量
- **强适应性**: 动态适应不同领域文档
- **好扩展性**: 模块化设计支持组件替换
- **可解释性**: 分阶段记录和决策追踪

## 📊 性能指标

### 测试结果
- **Schema检测准确率**: 88.9% (通用) / 85.7% (时空)
- **实体推断准确率**: 92.3% (6层) vs 78.5% (3层)
- **三元组抽取F1**: 0.89 (混合) vs 0.76 (纯规则)
- **处理速度**: 平均5-8秒/文档
